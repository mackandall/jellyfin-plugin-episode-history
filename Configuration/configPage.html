Guide marks

Puts symbols in front of each upcoming guide entry's episode title. Marks are household-wide (watched by any user). Entries with a scheduled recording are never marked.
Needs the JellyDVR Schedule plugin. Skipped for a tuner conflict, or recorded at another airing instead.

Recordings row and Recordings tab

A row on the web client's home screen listing what the DVR recorded, newest first, like SageTV's Recordings view. Recordings moved to an archive folder (e.g. by JellyDVR Space) stay in it, marked archived; viewers switch between All, Current and Archived on the row.
Each viewer's own pick on the row is remembered in their browser.
Off: one card per recording.
Programmes whose guide has no season and episode land in Live TV's general recording folder, which Jellyfin may not show in any library. Each gets a card here, with when it was recorded.
A recording is listed as soon as it starts, not only once it has finished. Live TV buffers that aren't kept stay out.
Files in the recordings folders too short to count as recorded (cut short, failed starts), so they're easy to find and delete. They never count for guide marks or duplicate skipping.
A recording the DVR made is listed as partial as soon as it ends short. This wait is only for files in the recordings folders the plugin didn't see being recorded (copied in, or cut off by a server restart): they are listed this long after they were last written.
Jellyfin's "Recently Added Recordings" lists everything in the libraries that hold the recordings folders, including files other DVRs recorded. The recordings grid shows only what this DVR recorded, archived ones included. "All Recordings" (the library tiles) stays either way.
The list by date has one line per recording, newest first, grouped by day, with the channel it came from. Viewers can switch between the two on the tab; their choice is remembered in that browser.
The channel's logo and number, from Live TV. Recordings made before this version, or not by the DVR, show without one.

Trash

As in Channels DVR: a delete from any app (JDVR, this web client, others) moves the files to a hidden .jdvr-trash folder on the same drive, and the item leaves the library. It can be put back from the list below until it's deleted for good. Off: deletes are immediate, as before.
After this many days in the trash, an item is deleted for good.
When a drive has less free space than this, its trash is deleted for good, oldest first, until it has enough. Checked every 10 minutes and after each delete. 0: off.
A NAS share with a recycle bin (#recycle) keeps whatever is deleted over the network, on the same disk, so emptying the trash would free nothing. With this on, the copy of the trash's own files is removed from #recycle too. Nothing else in #recycle is touched.

Styling marks in the web guide

With the web guide script installed (install-web.sh), marked guide cells get the CSS classes eh-marked, eh-watched, eh-inlibrary and eh-recordedbefore, and the symbols are wrapped in span.eh-mark. Paste rules like these into Dashboard → General → Custom CSS code (web browsers and apps built on the web client only; TV apps ignore it): 
/* Watched: italic, dimmed */
.programCell.eh-watched .guideProgramNameText { font-style: italic; opacity: .6; }

/* In library: colored episode line */
.programCell.eh-inlibrary .programSecondaryTitle { color: #64b5f6; }

/* Recorded before (deleted): grey */
.programCell.eh-recordedbefore .programSecondaryTitle { color: #9e9e9e; }

/* Bigger symbols, or hide them and rely on the styling above */
.eh-mark { font-size: 1.2em; }
/* .eh-mark { display: none; } */
